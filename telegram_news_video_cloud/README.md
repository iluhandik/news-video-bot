# 🌟 Telegram News Video Studio (Cloud & Autonomous)

Автономний хмарний сервіс та веб-студія для автоматичного монтажу вірусних відео (9:16) для **TikTok**, **Instagram Reels** та **YouTube Shorts** із вашого Telegram-каналу.

Працює повністю в хмарі — ваш комп'ютер може бути вимкнений!

---

## 🚀 Як запустити автономно на Render.com (Безкоштовно)

Render дозволяє запустити повноцінний веб-сайт із красивим дашбордом та відеоплеєром, який працює 24/7.

### Крок 1. Створіть репозиторій на GitHub
1. Перейдіть на [github.com](https://github.com) і увійдіть (або зареєструйтесь).
2. Натисніть кнопку **New** (Створити новий репозиторій), назвіть його, наприклад, `telegram-video-bot` і зробіть його **Public** або **Private**.
3. На сторінці нового репозиторію натисніть **uploading an existing file** (завантажити файли).
4. Перетягніть **всі файли та папки** з цього розпакованого архіву у вікно браузера та натисніть зелену кнопку **Commit changes**.

### Крок 2. Підключіть Render
1. Перейдіть на [render.com](https://render.com) та зареєструйтесь через свій GitHub-акаунт.
2. Натисніть кнопку **New +** у правому верхньому кутку та оберіть **Web Service**.
3. Оберіть ваш щойно створений репозиторій `telegram-video-bot` і натисніть **Connect**.
4. У формі налаштувань:
   * **Name**: вкажіть будь-яке ім'я (наприклад, `my-news-bot`).
   * **Runtime**: переконайтеся, що обрано **Docker** (Render визначить його автоматично завдяки файлу `Dockerfile`).
   * **Instance Type**: оберіть **Free** ($0 / month).
5. Натисніть **Create Web Service**.

**Готово!** Через 2–3 хвилини Render надасть вам посилання на ваш сайт (наприклад: `https://my-news-bot.onrender.com`).
Відкривши це посилання на телефоні або ПК, ви побачите стильний неоновий дашборд із відеоплеєром, можливістю монтажу в 1 клік та галереєю готових роликів.

## ⚙️ Автономний запуск за розкладом на GitHub Actions

У репозиторії вже налаштовано файл `.github/workflows/autopost.yml`. Завдяки йому сервери GitHub можуть автоматично перевіряти ваш канал і монтувати відео повністю безкоштовно.

1. У вашому репозиторії на GitHub відкрийте вкладку **Settings** → **Secrets and variables** → **Actions**.
2. Додайте ваші налаштування (натиснувши **New repository secret**):
   * `TELEGRAM_CHANNEL_ID` — юзернейм вашого каналу (наприклад, `@glavni_novyny`).
   * `CHANNEL_DISPLAY_NAME` — назва каналу для плашки.
   * `CHANNEL_USERNAME` — юзернейм каналу.
   * `TELEGRAM_BOT_TOKEN` — токен бота (якщо хочете, щоб відео автоматично надсилалися вам в особисті повідомлення Telegram).
   * `ADMIN_CHAT_ID` — ваш особистий числовий ID в Telegram.
3. Перейдіть у вкладку **Actions** угорі репозиторію та натисніть кнопку **I understand my workflows, go ahead and enable them**.
4. Тепер GitHub сам за розкладом щогодини перевірятиме нові публікації та збиратиме ролики. Ви також можете в будь-який момент натиснути кнопку **Run workflow** для миттєвої генерації.

## 🎨 Що входить до візуального стилю ролика:
* **Анімований Cyber-News фон** із глибоким градієнтом, сіткою та розсіяним світлом.
* **Картка посту Telegram**: круглий аватар, офіційна синя галочка верифікації, назва каналу, заголовок новини та лічильник переглядів.
* **Динамічні великі субтитри**: яскраво-жовті з чітким чорним контуром для легкого читання навіть без звуку.
* **Пульсуючий CTA-банер**: заклик до дії внизу екрана для максимальної конверсії у підписку на ваш Telegram-канал.
